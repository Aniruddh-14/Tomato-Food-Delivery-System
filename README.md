# Tomato

Tomato is a full-stack MERN food delivery web application inspired by real-world platforms like Zomato and Swiggy. The project simulates an end-to-end food ordering experience with a clean UI, scalable backend, and production-style architecture.

## Features

### User Features
- Browse restaurants and food items
- View detailed menus
- Add and remove items from cart
- Place food orders
- Fully responsive design

### Authentication
- User signup and login
- Secure authentication flow
- Protected routes

### Admin (Planned)
- Add and manage food items
- Manage orders
- View user activity
